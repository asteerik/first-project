# Ковчег Труда — Структура сайта

## 2. Структура страниц

### 2.1 Основные страницы
1. **Главная страница** - поиск вакансий, destacado вакансии, статистика
2. **Каталог вакансий** - список вакансий с пагинацией, фильтры
3. **Страница вакансии** - подробное описание, организация, отклик
4. **Регистрация** - выбор роли (соискатель/работодатель), формы
5. **Вход** - авторизация пользователей
6. **Личный кабинет соискателя** - резюме, отклики, избранное
7. **Личный кабинет работодателя** - вакансии, отклики, настройки
8. **О проекте** - информация о инициативе
9. **Помощь** - FAQ, правила, контакты
10. **Контакты** - форма связи, соцсети, карта

### 2.2 Структура данных

#### Пользователи и роли (Participant #3)
- User (Django auth) + роль (seeker/employer/moderator)
- Профиль соискателя: пользователь + телефон, навыки, опыт
- Профиль работодателя: организация + контакты, подтверждение
- Организация: имя, описание, категория, статус (pending/verified/admin)

#### Вакансии (Participant #3)
- title,organization, category, region, description, date_posted, status
- Связи: organization → Organization, author → User, categories → Category

#### Отклики (Participant #3)
- user → User, vacancy → Vacancy, message → текст, date → дата, status → new/accepted/rejected

#### Избранное (Participant #3)
- user → User, vacancy → Vacancy, date → дата
