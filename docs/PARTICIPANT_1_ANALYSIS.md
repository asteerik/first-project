# Ковчег Труда — Проект анализа и структура

## 1. Анализ потребностей пользователей

### 1.1 Типы пользователей
- **Соискатели**: Вакансии ищут, резюме создают, на вакансии откликаются, избранное сохраняют
- **Работодатели**: Вакансии создают, редактируют, отклики manage, организации проверяют
- **Модераторы**: Организации и вакансии проверяют, жалобы рассматривают, права управления

### 1.2 Основные сценарии
- **Найти вакансию**: Поиск по ключевым словам, фильтрация по региону и категории, просмотр списка и детальной страницы
- **Разместить объявление**: Регистрация/вход, заполнение формы вакансии, публикация
- **Откликнуться**: Поиск вакансии, просмотр описания, отправка отклика
- **Профиль**: Обновление данных, загрузка фото, настройка уведомлений

### 1.3 Потребность в данных
- Вакансии: titolo, организация, категория, регион, описание, дата, статус
- Резюме: имя, навыки, опыт, образование, контакты, статус приватности
- Организации: название, описание, категория, контакты, статус проверки
