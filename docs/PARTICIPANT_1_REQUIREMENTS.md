# Ковчег Труда — Требования к данным

## 5. Поля для вакансии
- **title** (заголовок): максимум 200 символов, обязательное поле
- **organization** (организация): связь с моделью Organization, обязательное
- **category** (категория): выбор из - education, social, clergy, charity; обязательное
- **region** (регион): выбор из - moscow, spb, nk, other; обязательное
- **description** (описание): текстовое поле, минимум 50 символов
- **requirements** (требования): текстовое поле (опционально)
- **salary** (зарплата): строка формата (опционально)
- **contact_info** (контакты): email/телефон (опционально)
- **is_active** (активность): boolean, по умолчанию True
- **date_posted** (дата публикации): auto_now_add
- **author** (автор): связь с User, отработка Participant #3

## 6. Поля для резюме
- **user** (пользователь): связь с User, одно на пользователя
- **full_name** (ФИО):.CharField max_length=100
- **skills** (навыки): ManyToManyField к навыкам или CharField с запятой
- **experience** (опыт): TextField или выбор лет/месяцев
- **education** (образование): CharField max_length=200 (опционально)
- **photo** (фото): ImageField upload_to='resumes/', валидация размеров (опционально)
- **is_public** (публично): BooleanField, default=False (защита резюме)
- **date_created** (дата создания): auto_now_add

## 7. Поля для профиля организации
- **name** (название): CharField max_length=200, уникальное
- **description** (описание): TextField
- **category** (категория): выбор сategory, matching вакансий
- **website** (сайт): URLField (опционально)
- **contact_email** (email): EmailField (опционально)
- **contact_phone** (телефон): CharField max_length=30 (опционально)
- **logo** (логотип): ImageField upload_to='org_logos/', валидация (опционально)
- **is_verified** (верифицировано): BooleanField, default=False (модератор)
- **date_founded** (год основания):.IntegerField (опционально)

## 8. Действия пользователей

### Соискатель
- Регистрация с выбором роли
- Создание/редактирование резюме
- Поиск и просмотр вакансий
- Отклик на вакансию (текст + кнопка)
- Сохранение в избранное
- Настройка уведомлений

### Работодатель
- Регистрация и подтверждение организации
- Создание/редактирование вакансии
- Просмотр откликов на свои вакансии
- Управление статусом вакансии (опубликовано/архив/закрыто)
- Профиль организации

### Модератор
- Проверка организаций (сменa статуса на verified)
- Проверка вакансий (прием/отклонение)
- Управление жаловами
- Расширение прав при необходимости
