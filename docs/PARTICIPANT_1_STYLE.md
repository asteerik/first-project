# Ковчег Труда — Визуальный стиль

## 3. Цветовая палитра
- **Основной зеленый**: #2d5a27 (тема, заголовки, навбар)
- **Вторичный зеленый**: #3d8b40 (акценты, кнопки)
- **Золотой акцент**: #d4a853 (подсветка, иконки)
- **Светлыйgold**: #f5e6d3 (фоны, hover-состояния)
- **Фон**: #f9f9f4 (Light gray-white)
- **Текст**: #333333 (основной), #666666 (вторичный)
- **Белый**: #ffffff (карточки, карточки вакансий)

## 4. Шрифты
- **Основной**: Nunito, sans-serif
- **Веса**: 300 (light), 400 (regular), 600 (semi-bold), 700 (bold)
- fallback: system-ui, sans-serif

## 5. Иконки и изображения
- Теле subtle иконки православных мотивов (крест, арка)
- Логотип: "Ковчег" + "Труда" в золотом цвете на зеленом фоне
- Изображения организаций: квадратные, светлый фон, тень 2px

## 6. Правила использования
- Контрастность текста/фон не менее 4.5:1
- Зеленый цвет использовать для успешных действий и навигации
- Золотой цвет - для акцентов и highlights
- Текст темно-зеленый на светлом фоне для основного контента
- Адаптив: мобильная версия сжата, но все элементы доступны

## 7. Макеты страниц (участник #2)
1. Главная - hero section + фильтры + карточки вакансий
2. Каталог - список с фильтрами по Sidebar
3. Карточка вакансии - фото, детали, кнопка отклика
4. Формы -_inputs, кнопки, сообщения об ошибках_
5. Личный кабинет - навигация по табам
